Same music. Five ways to hear it.

Compare the opening of game01, game07 and game08. Every version uses the game's AdLib arrangement and instrument bank, with the same ordered chip-register events. Only output processing changes.

Use headphones and switch during the same passage. Loudness is matched with constant gain, without compression. More precision may be a very subtle change; the warm filter is deliberately more audible.

Press Play to start. Switching versions keeps your place, with a short loading gap.

This is an offline audition, not an Android playback change. All listening files are 48 kHz stereo PCM16; the precision experiment keeps more detail before final conversion. The warm filter is a tonal option, not a measured recreation of a particular Sound Blaster.

Both warm versions have the same 8 kHz cutoff. One pole preserves more treble above that cutoff, but starts softening the frequencies below it more gradually. Compare against Clean resampling to check whether game08's riffs survive.

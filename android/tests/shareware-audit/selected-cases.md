## Static evidence

- Save namespace: `android/app/src/main/cpp/shared/state_android_shared.c:214-219` returns `Current_mission_filename`; `android/app/src/main/cpp/shared/android_save_set.c:64-73` sanitizes an empty mission to `default`. The checked-in public baseline at `android/test_fixtures/secret_area_shareware_baseline.json:10,2480` has D1 empty filename and D2 `d2demo`, proving the narrow missing-pilot path override.
- Guidebot: `android/test_fixtures/secret_area_shareware_baseline.json:3002,3062-3067`, `games[game=d2].levels[level_num=1]`, reports `guidebot_count=1`, `guidebot_placed=true`, `guidebot_accessible=true`, `route_status=ok`, and the first route step in segment 0. This supports retaining the D2 route certificate/rescan assertions after quick load. It does not prove runtime certificate or pause behavior.
- Intro fallback: `d2/main/titles.c:247-428` sets `g_intro_active`, falls back from movies to shareware logos, and requests title music after applying the skip preference. Thus intro/prefs/title-request tests do not require retail movie content.
- Public campaign limits: `d2/main/mission.c:240-255` selects three PC demo levels and zero secret levels. The selected death case uses level1; `async_checkpoint_unified` remains excluded because it explicitly expects secret level-1.

## Validation priorities

1. Run both save/load variants first: confirm D2 certificate/rescan, exact slot labels, missing-pilot path and resume pause release.
2. Run controller compare and prefs in both engines, ensuring isolated public staging cannot reuse existing retail files.
3. Run all graphics cases on supported GLES/MSAA device hardware; retain their original errors/state/energy assertions.
4. Run the full 51-variant matrix serially because device state is shared. Report each variant as PASS, FAIL or NOT RUN; catalog and script-preparation checks do not substitute for execution.

The optional `ogl_gauge_batch_unified -ASSETS d1_in_d2` parameterization is additional to the 51 native game variants. It must select the D1 public title (`Descent Demo`) inside D2 rather than inheriting `Descent 2 Demo`; its assertions also remain NOT RUN.

# PO2 engine feature compatibility study

## Goal

Correlate the advertised Plutonian Outbreak 2 features with the original archive contents and identify the Rebirth engine work needed for progressively better support.

## Work

- [ ] Inventory and identify every PO2 mission, data, patch, sound, music, and documentation file.
- [ ] Compare PO2 level and HOG metadata against stock D2/Rebirth capabilities.
- [ ] Research the original executable patch and later D2X-XL compatibility implementation.
- [ ] Trace each advertised feature to likely file formats and Rebirth engine subsystems.
- [ ] Produce a prioritized compatibility assessment with uncertainties and recommended investigation steps.

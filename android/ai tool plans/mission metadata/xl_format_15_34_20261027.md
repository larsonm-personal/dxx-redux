# XL 15/34 format support

The pinned XL loader enables packed light indices at game-data version 34.
The surveyed Apocalyptic Factor XL archive contains fifteen 15/34 levels, all
currently rejected by the version gate. This tranche must establish decoding,
native translation and controlled Android lifecycle behavior before admitting
the layout. Independent gameplay/resource requirements remain enforced.

1. Audit the source header, geometry, object-trigger and light-index branches
2. Compare every original light index with extracted CLightDeltaIndex::Read;
   retain old 15/33 controls and malformed packed-count/side/extent checks
3. Inspect all fifteen unchanged originals and record independent blockers
4. Verify native geometry, objects, light application and save-through-stock
   on a clearly derived fixture while retaining original blockers, without navigation
5. Register and run controlled Android load/light/save/restore checks
6. Run focused regressions, source compiler checks, catalogs and formatting;
   document evidence, push a separate stacked PR and require green CI

Loading or decoding does not qualify original campaign gameplay.

## Results

The source reader confirms fourteen originals have invalid packed light ranges.
Alarlof alone decodes, but its original HXM remains rejected. The derived native
fixture removes only that HXM member, leaving all RL2 bytes intact. All 68 light
sources, 5,083 deltas and stock round-trip persistence pass. Android's 48-step
owned integration passes, including saved one-shot light state. Exact scope,
hashes, failed test assumptions and final controls are in
[format evidence](../../XL_compat/evidence/format-15-34.md).

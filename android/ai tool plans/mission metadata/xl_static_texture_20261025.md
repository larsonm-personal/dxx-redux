### Proposed order and acceptance

1. **Source classification and static binary transparency.** Classify original decoded pixels before fitting, mip generation or color conversion, retaining distinct ordinary-alpha and purple-key coverage. The current static slice rejects both; its oversized mixed-key regression must demonstrate that ordinary resizing erases the exact RGB key while scoped admission still rejects the source. Next, wire binary alpha cutouts and purple holes into existing Redux shader/mask paths, preserving same-owner color/mask provenance and POG precedence. Ordinary overlay alpha reveals the base wall texture; purple super-transparency removes the combined coverage and reveals geometry behind. These are different operations, not one blend flag. First original witness: BoilingPoint `fan03.tga`, with `misc075.tga` as a second keyed shape. Ordinary binary cutouts use synthetic fixtures until a real authored witness is found. Acceptance: a three-layer base/overlay/behind scene, all four overlay rotations, sparse key before/after fitting, mixed alpha/key classification, same-source masks, and correct far/mipmap edges. Verify the native material flags and load context for the original witness; no whole-level admission is required.
2. **Opaque wall and door animation.** Use one verified wall/eclip strip first (`force01#0.tga` is a candidate), then the door/wclip witness `door53#0.tga`. Honor exact `name#n` lookup before `name#0` fallback, existing mission ownership and custom POG priority. Do not flatten the strip into an ordinary tall texture. Validate square frame geometry, source bytes, decoded bytes, GPU allocation and an explicit maximum of 128 frames; reject malformed dimensions and 129 frames rather than truncating counters. The 128 proposal follows the pinned source's four 32-bit frame-mask words and remains subject to actual witness qualification. Keep immutable per-frame source metadata. Prefer per-frame uploads or texture-array layers over an atlas with cross-frame mip bleeding. Reuse current texture caches, adding owner generation and selected frame to any derived/merged cache key; never decode files per frame.
3. **Animated masks, then partial-alpha materials.** Only after the opaque frame adapter is stable, switch color and mask frames atomically, including a key appearing only in a later frame. Then qualify partial alpha separately using `metl100.tga`, `metl111.tga` and `metl128.tga`: depth writes, draw order, cutout thresholds, premultiplied filtering and intersecting surfaces must be tested before enabling blending. Retain unsupported/partial metadata distinctions for each class. Sprite/vclip animations come later with their own `play_time`/`lifeleft` adapter; cockpit composition is also separate.

### Time, state and lifecycle contracts

Replacement frame count must not rewrite `Effects`, `WallAnims`, clip durations, simulation timers or RNG. Redux eclip updates include one-shot gameplay side changes, so changing the eclip rate to suit artwork would change gameplay. Sample replacement frames through render-time adapters from the authoritative wall/eclip and door/wclip state, preserving the original cycle duration, door reverse/hold behavior and one-shot completion. A different authored replacement frame count changes presentation sampling only. Pause must freeze the sampled phase. Save/reload must reconstruct that phase from native state; any genuinely new authoritative phase would require an explicitly versioned save/replay design, not an implicit global timer.

Acceptance must compare SIM/RNG state at different render FPS, before/after pause and native save/reload, while checking frame progression. Use 1/2/128/129-frame fixtures, different replacement-versus-classic frame counts, duplicate frames, reversed doors and stopped/one-shot clips. Test mission A -> B -> stock -> A, level and secret-level changes, failed loads, and GL context recreation. These follow-ons need full production lifecycle coverage in addition to the controlled renderer fixture. Resource caches must be invalidated by mission identity/generation; a reused bitmap name must never borrow another mission's frames or mask. The browser should report detected, classified and renderer-qualified resources separately, with unknowns preserved, and must not decode assets on a tap.

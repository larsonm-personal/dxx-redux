# Owned XL classic sound replacements

Pumo supplies 196 WAV files matching 142 of the retail D2 bank's 183 sample
names. These are separate consumers from named sound actions and ambient
objects. Implement their resource foundation before relying on a complete
mission audio profile, without granting playback or campaign qualification
from successful decoding.

## Work

1. Execute the pinned `LoadHiresSound`, `SetupSounds`, `VerifyHiresSound` and
   `LoadD2Sounds` selection rules with independent file/bank adapters. Check
   normal and secret folders, missing files, bank suppression, unknown names,
   high-resolution fallback and the retained Redux alternative.
2. Prepare a bounded immutable bank using the selected mission's captured
   ownership and incoming signed ordinal. Preserve stereo WAVs and exact
   selected paths/content. Reject unsupported selected custom banks and foreign
   or malformed preferred resources instead of silently using defaults.
3. Compare all selected original Pumo resources against independent bank names,
   folder selection and WAV decoding on Windows and Linux. Inventory mission
   INI settings separately; fifteen config files contain no audio overrides.
4. Add production loading/output only after the source channel behavior is
   understood. Keep resource selection, actual output, spatial consumers,
   shared channel priority and persistence as separate evidence obligations.
   If this increment ends at preparation, retain an explicit admission gate
   for unapplied replacements.
5. Run affected public/private owners and actual Android controls if runtime
   behavior changes. Complete scoped formatting and required catalogs, update
   evidence, then publish the reviewed increment stacked on the sound-folder PR.

Do not navigate levels, alter original distributions, merge PRs or modify the
main checkout. Keep completion claims tied to tested consumers, not file counts.

## Implemented boundary

This increment completes resource preparation and closes silent stock fallback;
it does not install classic replacement voices. The pinned source selects the
same 1,988 original Pumo level/sample resources as the production provider and
independent bank/folder reader. All 196 selected WAVs have matching decoded PCM
on Windows and Linux. Normal loading now explicitly rejects unapplied WAVs and
selected custom banks before changing live playback.

All 206 additional source cases, native preparation/rejection controls, 43/46
public checks, 65 Android output/persistence steps and 27 Android menu rejection
and stock recovery steps pass. Scoped formatting, direct PowerShell analysis
and both automation catalogs pass. The final private owner passes all 103
required controls after fixing repeated sound-directory scans; no timeout was
increased and no check was removed.
See [evidence](../../XL_compat/evidence/classic-audio-bank.md) for receipts.

The next audio work should establish XL's channel allocation, persistence and
spatial controls before admitting ordinary replacements or ambient objects.
Redux currently has a separate channel path; do not mistake asset installation
through that path for XL volume, panning or shared-priority fidelity.

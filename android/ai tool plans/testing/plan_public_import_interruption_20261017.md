# Interrupted public mission replacement

Extend the existing PublicFirstPlay owner, before its D2 phases. Generate two
bounded stored ZIPs from pinned unchanged D1 shareware level bytes. Import and
normally launch old content; interrupt a replacement during nonzero incomplete
extraction through an androidTest-only progress barrier. Verify old ZIP/manifest
identity and a real old-mission launch, allowing cache regeneration. Retry the
same replacement bytes through the ordinary launcher callback and normally launch
the new mission. Require correlated results, hashes and native D1 evidence.

Production stays unchanged unless this test reproduces a failure. No new campaign,
private assets, device-wide settings or local SDK/PowerShell execution. Add focused
negative controls and use existing hosted catalog/format checks. The 1080-second
owner estimate fills the existing single-emulator lane's 2700-second budget; only
hosted completion can qualify that estimate. D2 failures remain visible. This does
not cover real ENOSPC, power loss or the internal rename-to-backup crash window.

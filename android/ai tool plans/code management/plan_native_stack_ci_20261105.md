# Native stack CI

- Inspect existing public and trusted private workflows and documented native stack metadata
- Preserve cheap per-PR checks and existing expensive check identities
- Refresh native membership before expensive job groups; run on uncertainty
- Recheck after builds/planning to skip later stages of a demoted tip
- Keep private admission and status publication coherent; do not publish a pass for a skip
- Cover full-stack changes and preserve manual, scheduled and push behavior
- Validate policy regressions, workflow expressions, formatting and existing controller tests
- Publish a separate draft PR from current cmake, without merging or rewriting history

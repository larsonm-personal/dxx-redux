## Concrete source-derived defect

music_soundfont_validate allows a nonterminal sample header end equal to the complete smpl sample count. Pinned TSF allocates exactly smplCount floats, sets resolved region end to fontSampleCount at the boundary, and renders while source position < region end. Nonloop interpolation evaluates input[pos] and input[pos+1]. music_soundfont_load_memory rejects end > samples, allowing end == samples. Rendering the last nonloop sample can therefore read one float beyond the allocation

An admitted symbolic input has one preset, one instrument, one nonloop sample and terminal records: phdr/inst/shdr counts2; pbag/ibag counts2 with first generator index0 and terminal1; pgen/igen counts2 with instrument41=>0 and sampleID53=>0 followed by terminal records; pmod/imod count1 and all modulator indices0. Sample storage contains2 shorts; shdr start0/end2/rate48000/key60, loops0 and non-ROM type. INFO ifil2, exact even LIST/table lengths and required tables satisfy validator structural/index/expansion gates. TSF creates one region offset0/end2 with loop_mode NONE and allocates2 floats. At position1, interpolation nextPos2 is outside the buffer. This is a source reasoning witness, not generated bytes or an executed reproducer; SF2 specification compliance is not asserted, only admission by the maintained validator

The same reachable boundary exists for resolved end offsets clamped to total storage and for loop release. Source-end header checks alone do not establish resolved interpolation safety. No claim that normal padded bundled banks exhibit this issue

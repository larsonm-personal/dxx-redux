# General Code-Quality Done Ledger

This is the canonical archive for terminal `GQF-*`, `GQI-*`, and `GQR-*` records from the general code-quality campaign. Coverage queue rows and completion notes remain in `general_code_quality_ledger_20260811.md`

## ID and archive rules

- IDs remain unique across the active and done ledgers
- Move a complete record here only in the same ledger transaction that assigns its terminal disposition
- Preserve original frozen evidence, historical links, resolution date, exact change boundary, validation, limitations, and root acceptance
- Terminal finding states are `FIXED`, `DISMISSED`, `DEFERRED`, `DUPLICATE`, `RESOLVED_EXTERNAL`, and `OBSOLETE`
- A deferral names an owner or milestone, reason, accepted risk, and recheck trigger
- Partial mitigation remains in the active ledger
- A regrown historical issue receives a new generation-specific active finding linked to its archived predecessor

A claim of full support needs a named corpus and platforms. For each single-player release, account for every advertised ordinary and secret ordinal and each authored exit. Preserve an earned chain from a fresh pilot to the ending, with checkpoints around keys, switches, rescue, reactor or boss objectives. For a competitive-only release, use its advertised mode, scoring and match end. Record each archive with a missing member or an original-engine refusal as a distribution outcome, with the original bytes and source of any replacement. Keep those entries visible in the 1,654-entry accounting.

Start each shared fix by finding the same player-visible event in Redux and the pinned original. Compare the inputs, owning resources, event and resulting state, implement the correction in Redux, then repeat the event on a second author's level and replay the original regression. The short per-PR checks can protect known fixes while longer sharded jobs cover earned routes, multiplayer and cold restarts. The 64-case run took 264 seconds locally on the renderer candidate. Adding a one-minute earned interaction would still leave time to measure provisioning under the ten-minute CI limit.

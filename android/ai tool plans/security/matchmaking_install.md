# Reentrant public matchmaking installer

Implement a single Debian/Ubuntu systemd entry point for the current checkout. Preserve the existing server config/database, overlay production transport/auth settings, build with the CI Rust pin, bootstrap HTTP ACME before TLS, install automatic renewal, and verify HTTPS readiness/auth routing. Save changed managed files and roll back on failure. Never reset firewalls, pull Git implicitly, or print secrets.

Validation: Bash syntax and shell lint; hermetic mocked-command integration covering first install, unchanged rerun, certificate failure, nginx failure and daemon/readiness failure. Real VPS/DNS/ACME/UDP qualification remains external and must not be claimed by local tests.

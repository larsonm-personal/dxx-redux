# Registered Tulev1 level 7 supplies owner

This is an incremental, assisted-local test owner after the public courtyard guard
owner. It does not replay the campaign itself. The default CTest composition uses
fixtures; an incremental qualification can invoke `pumo_tulev1_supplies.cmake`
directly with an already verified courtyard output and its public producer closure.

The owner accepts only the one versioned guard305 save produced by that courtyard
chain. Each later phase copies only the immediate producer's versioned save into a
fresh profile. Every phase launches a new process with a new receipt nonce. The
order is an ordinary Quad Laser shot on switch 6, a cold no-frame resave, a
physical Cloak 113 pickup, a cold no-frame resave, a physical Guided 140 pickup,
and a final cold no-frame resave. No inventory grant, direct trigger or damage
call, actor freeze, or collision bypass is part of the control stream.

The warm controls use one explicitly declared local setup assist. The switch pose
is an authored test input. The later poses keep the actual immediate predecessor
position and change only the authored view, with all motion supplied by ordinary
controls. The source-only contract checks the public producer closure, executed
plan binding, save hashes, fresh processes, trace steps, ordinary inventory and
gate outcomes, actor identity and health, and per-frame observed full-hull actor
clearance. Cold resaves compare the complete immediate predecessor save,
including hidden state. The only permitted difference is source-defined
normalization of the alternate-texture field from zero to minus one on an
inactive polymodel object slot during restore. The contract independently
parses both save tables, checks slot type and render type, and requires every
other byte to match. This exception does not apply to active objects or other
fields. It treats same-tick entry and stock Guided pickup as valid. Scene actor
snapshots are distance-filtered, so the contract first recovers the full saved
actor table for radius and identity checks; it does not infer that an unseen
actor is absent. Per-frame checks are sampled, not continuous collision proof.

Source-only contract tests use synthetic fixtures and mutation negatives. Actual
native qualification requires a separately reviewed frozen invocation packet,
exact input and output paths, bounded timeout, external retention and capacity
checks, and explicit release. Keep raw asset, save, geometry and measurement
evidence outside the public tree. Preserve any failed runs and perform separate
read-only adjudication rather than editing their validators or output.

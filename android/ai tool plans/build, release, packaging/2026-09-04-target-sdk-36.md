## Findings

- Google Play requires API 36 for mobile submissions and updates from August 31, 2026: https://support.google.com/googleplay/android-developer/answer/11926878?hl=en
- Existing compile SDK 37, AGP 9.3.2, and AndroidX dependencies already support the new target; retain their pins and min SDK 23
- Android 16 stops legacy Back dispatch by default; opt native game and preview activities out while retaining AndroidX Back handling in SetupActivity
- Declare appCategory=game so Android 16 preserves game orientation constraints on large screens
- Existing windows already use edge-to-edge layout; no edge-to-edge opt-out was present
- Extend robot and level preview integration tests to close through system Back and verify native cleanup and launcher return
- Android 16 behavior reference: https://developer.android.com/about/versions/16/behavior-changes-16

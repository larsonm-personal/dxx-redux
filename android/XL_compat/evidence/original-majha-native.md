## Gate

missions/mods/data directory, plus existing native engine/retail-data settings.
It requires a desktop GL3 context/display and PowerShell Core. Run the reusable
`tests/pumo_player.cmake` with ENGINE, DATA, RESOURCES and OUTPUT. It stages a
private resource copy and profile after retention/reserve checks. No installer,
proprietary asset bundle or DXA builder is produced.

The gate reads the same Majha action/expectation source used by the protected
Android owner. It explicitly adapts the completion-menu boundary to native
no-render's automatic normal level4 arrival; it does not force that transition.
Original HOG/MN2/VHAM hashes, full mission model/weapon definitions and owned
HAM/HXM/VHAM/OOF are required. Missing original resources are rejected before
runtime startup. Source/stage SHA256 manifests matched all2670input files.

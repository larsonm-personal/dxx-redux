# Gameplay tranche capability audit

G0 checkpoint, November 11, 2026. This is an implementation and qualification
map, not a claim of full single-player support. The source baseline is
`e87f4bfaeec60fd7a9697488413e02cc88230ade`, tree
`3828501abd12c10e803ea8b215bc12a991c037bc`, plus the baseline CI fixes on
`xl_gameplay_20261111_01_baseline`. Reference semantics use
`2576a98b5de310e3ac7c9777df2677d1627b8bae` in `temp/d2x-xl-reference`.

The existing 19-category catalog contains chronological descriptions that have
been superseded by its linked evidence and current admission code. In particular,
extended HOGs, modern layouts, spawn points, stationary effects and generated
bosses already have implementations. Their former blanket rejection descriptions
must not be used to invent new work or to claim current qualification.

Evidence classes below mean: **proved** within the cited bounded controls;
**implemented/unproved** for the requested integrated gameplay/replay contract;
**missing gameplay** for a valid behavior without its required implementation;
**presentation-only** only after tracing simulation consumers; **invalid content**
only after a source/record audit; **unavailable genuine content** for exact missing
inputs. Unknown validity remains unresolved, not invalid or cosmetic.

# Original-spawn Tulev1 gate and guided pickup witness

The new Tulev1 spawn owner passed a fresh authenticated, untraced run of the registered original-asset suite: 8/8 tests, exit 0, 496.70 seconds. This is a bounded level-7 witness from the actual preserved Sophodo warm arrival in segment 1183. It proves assisted local access through three ordinary doors and consumption of one Guided pickup in that order. It does not prove a continuous or unaided corridor flight to segment 647, remote grate or switch 12, boss, exit, or level-8 progression. It does not turn the prior pose-assisted 458-side guided group into a connected route across the blue gate.

## Verification and limits

The serial original suite timings, in seconds, were Majha 34.59, Metillis 43.92, Coldrom 42.47, Iquaxel 54.05, Sophodo 132.02, Tulev1 early 98.20, Tulev1 spawn 66.81, and Guided input 24.64. The new spawn owner is a separate successor to Sophodo; the seven prior owners retain their criteria and budgets. The new aggregate limit is 300 seconds and inherited per-phase 150-second ceilings are unchanged. FAST and readiness rules are unchanged. Hosted exact-head PR checks remain pending and cannot substitute for the original eight-owner suite.

Public EGL passed 58/58 in 44.45 seconds, including the new unconditional asset-free spawn contract after reconfiguration. Private original-asset policy passed 36/36. Its first invocation lacked CMake on `PATH` and stopped before assertions; the same tests passed after the existing tool environment was loaded, and the first log was retained. Pinned Ruff, scoped CMake lint/format, pinned Prettier and diff checks passed. These are scoped checks, not a whole-tree quality pass; the repository has unrelated inherited CMake formatting hunks.

The first private prototype was not the final qualification. Door 127 and 211 native phases and validation passed, and Guided 137 native phase passed, but the private validator mistakenly checked ammo slot 4 instead of 6. Its old output and checker were retained. A minimal offline correction validated the unchanged Guided 137 output without rerunning phases 1-3. Door 138 then ran as a separate approved continuation. Only after that did a new full 8/8 suite pass with the canonical checked-in plans and strict checker; old receipts were not relabeled as the formal run.

Reproduction requires the original resource root and the existing Release engine. Run the registered original suite with its normal `ctest` configuration and verify all eight owners, then run the public EGL and policy suites in the configured environment. Do not publish the original resource root or retained raw outputs.

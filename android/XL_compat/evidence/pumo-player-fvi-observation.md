# Pumo player physics FVI observation

A developer-only observer now samples the local player's actual physics FVI result. It is null by default, enabled only by an opt-in native Pumo plan, and compiled under the dedicated `DXX_PUMO_CONTACT_DEVELOPER_PROBE` macro. The macro appears in the developer headless metadata target's C and C++ flags, but not the production game, ordinary headless game, or metadata worker flags. The developer lifecycle binary contains the observer symbol. The hook does not run an extra FVI or collision query, change physics, or use recorder mode.

The observer filters a single source segment and stores only the first four and last four results, with a total sample count. It captures the ordinary query and result after the existing skybox adjustment. Object identity and robot attributes apply only to `HIT_OBJECT`; wall identity and doorway values apply only to `HIT_WALL`. A wall result may make a read-only doorway lookup, which could warm a texture cache. These observations are diagnostic, not a gameplay qualification.

The branch is stacked on the native wall-contact observation at `1caacf82b7b05cd240d23cd934dd791c340c743c`. Frozen source SHA-256 values are: `d2/main/physics.c` `b25418b51d50631ea1ea54d6870e2286ff54e837cb5451cd9773075b4750fe61`, `d2/main/physics.h` `b653904f03359c9b091700c5409fb26792fa969450180d5cb2398a097d1f5285`, and the developer Pumo header `6b4e5e297da16c258f726aae1d46d938fcd57cec048867d708b35dd82b9c930d`. The isolated Release executable is SHA-256 `cef3c75dc6625d862abbf239dfff9bc29fb454580472bcbddd0393426f6beeb9`. Build checks passed: 3/3 focused classic tests, 57/57 public EGL checks, and 36/36 private asset-policy checks. Independent source and target-scope checks found no production observer definition.

Two paired runs used the same earned switch-open checkpoint and ordinary controls. A fixed five-second wait reproduced the earlier crossing stall for diagnosis; it did not replace the original failed pickup criterion. Observer-off and observer-on runs each passed their eight diagnostic steps. All eight corresponding state snapshots matched exactly, and the full final-state files were byte-identical, including RNG state and call count. The player remained alive and uncloaked, and the authored pickup remained unconsumed. The observer reported 300 source-segment samples, but retained only eight. All eight retained results were object hits against the same robot identity; its loaded energy-drain and attack-type fields were both zero. The other 292 results were not classified by this bounded record.

The retained results support a repeated physical actor obstruction at the observed boundaries of the stall. They do not show a wall hit, establish the cause of any energy change, prove that every frame hit that actor, or qualify the pickup or level route. No doorway bug or gameplay fix is established.

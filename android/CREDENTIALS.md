# Local credentials

All files below are gitignored. Back up private keys securely; never commit them or put OAuth client secrets in an APK. Paths are relative to `android/`.

| File                                                      | How to populate                                                                                                                                                                                                                               |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `release.keystore`                                        | Preserve the existing signing key. For a new application only, generate a Java keystore with `keytool -genkeypair`; see `keystore.properties.example`. Losing/changing the GitHub signing key breaks normal APK updates                       |
| `keystore.properties`                                     | Copy `keystore.properties.example`; set the keystore path, alias and passwords. The Play upload key may be the same local key; Play's delivered APK signing certificate is separate                                                           |
| `play-store-credentials.json`                             | Create a Google Cloud service account, grant the required app release permissions in Play Console, and download its JSON key; see `play-store-credentials.sample.json`. This is for publishing, not player sign-in                            |
| `credentials/dxx_revival_server-client_secret_*.json`     | In Cloud project `dxxrevival`, create an OAuth **Web application** client; leave JavaScript origins and redirect URIs empty for our native ID-token flow; download JSON                                                                       |
| `credentials/dxx_revival_github-client_secret_*.json`     | In the same project, create an **Android** OAuth client for `com.dxxredux.app.github` and the SHA-1 of the release keystore certificate; download JSON                                                                                        |
| `credentials/dxx_revival_play_store-client_secret_*.json` | In the same project, create an **Android** OAuth client for the actual Play application ID (`com.dxxrevival.app` in the release instructions) and the **Play app-signing** SHA-1 from Play Console, not the upload certificate; download JSON |
| `auth_config.jsonc`                                       | Copy `auth_config.template.jsonc`; use the Web export's `client_id` as `matchmaking_google_client_id`. Set the same ID as server `GOOGLE_CLIENT_ID`. Leave `games_app_id` zero unless separately configuring optional Play Games              |

Run `./gradlew.bat :app:signingReport -PgithubRelease=true` from `android/` to obtain the release certificate fingerprint. Debug certificates and the legacy GitHub package need separate Android OAuth registrations. OAuth exports are local records, not automatically consumed by the build. The server verifies Google ID tokens and does not need the Web client secret.

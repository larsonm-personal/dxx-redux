D2 textures: original files for d2x-xl by Aus-RED-5D, DizzyRox, MetalBeast, Novacron, Theftbot
D1 textures: original files for d2x-xl by DizzyRox, Novacron, Aus-RED-5

These DXA files are converted from the d2x-xl hires texture and sound packs.
The conversion scripts (convert_all.ps1, convert_d2xxl_textures.ps1,
convert_d2xxl_sounds.ps1) repackage the original 7z archives into DXA
format for use with dxx-redux on Android. find the conversion scripts in redux git
